# Roadmap

This document lists possible future work, not committed release scope. Priorities may change as real use cases emerge.

## Secret Resolution

- Parameter version selection for AWS SSM
- Secret caching
- Secret rotation detection
- Permission validation
- Health checks for secret availability

## Runtime Integrations

- Kubernetes operator library interface
- Container init mode
- Configuration hot reload

## Security And Operations

- Best-effort cleanup of secret values from memory
- Audit logging without secret disclosure
- Structured logging
- Prometheus metrics
